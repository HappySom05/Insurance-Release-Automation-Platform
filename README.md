# Insurance Release Automation Platform

## Project Overview

Insurance Release Automation Platform is a DevOps-based project designed to automate application build, testing and deployment processes.

The objective of this platform is to reduce manual effort, improve deployment accuracy and accelerate release cycles using DevOps practices.
